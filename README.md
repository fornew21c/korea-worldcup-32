# 🏆 2026 월드컵 우승 예측 브래킷

좋아하는 팀을 한 경기씩 눌러 **32강 → 16강 → 8강 → 4강 → 결승**까지 직접 진출시키며 나만의 우승팀을 예측하는 인터랙티브 토너먼트 브래킷입니다. (본선 32팀 · 총 31경기)

- 🖱️ 승자 클릭 → 다음 라운드 자동 진출
- 🔁 상류 경기 픽을 바꾸면 하류 픽이 연쇄 해제(cascade)
- 🏆 우승팀 확정 시 트로피 카드 + 컨페티 🎉
- 🎲 랜덤 시뮬레이션 / 초기화
- 📊 예측 진행도 게이지, 상단 전광판에 "나의 우승팀" 표시
- 📱 모바일 가로 스크롤 · 키보드 대응 · `prefers-reduced-motion` 존중

단일 HTML 파일(`index.html`)로 동작하는 정적 페이지입니다. 외부 의존성 없음.

> 대진은 본선 진출 32팀으로 구성한 참고용 토이이며, 실제 2026 본선 대진 추첨과 다를 수 있습니다.
